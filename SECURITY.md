# Security

Report a security problem privately through [a security advisory](https://github.com/GeorgeGedox/homeproxy/security/advisories/new). Do not open a public issue for it.

Say what an attacker can do, how to reproduce it, and which version you run. Do not include your own tokens, passwords or keys.

One person maintains HomeProxy, so there is no fixed response time. Fixes go into the next release.

Only the latest release gets security fixes.
